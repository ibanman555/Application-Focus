# Application Focus for Stream Deck

Bring an **already-running application** to the foreground with a Stream Deck button. Restores minimized windows. **Never launches the application or opens another instance.**

## Installation

1. [Download the plugin](Application_Focus_for_Stream_Deck_v1.0.3.streamDeckPlugin).
2. Double-click the downloaded `.streamDeckPlugin` file to install.
3. Add **Application Focus → Focus Existing App** to a Stream Deck button.

## Settings

- **Application:** Select a running program or enter its `.exe` name.
- **Window title (optional):** Focus a particular window.
- **Show button confirmation:** Show a checkmark on success or an error on failure. Uncheck to hide both.

**Requirements:** Windows 10/11 and Stream Deck 7.1+.
